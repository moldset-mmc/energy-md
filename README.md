# Energy MD

Многостраничный атлас предприятий и организаций Республики Молдова для поиска потенциальных покупателей электроэнергии от **30 000 MDL в месяц**, с приоритетом дневного потребления.

Сайт: **https://energymd.vercel.app/**.

Интерфейс и 118 карточек доступны на русском и румынском (RU / RO). Язык запросов выбирается отдельно от языка источников. Оригинальные PDF/XLSX сохранены; CSV текущей выборки использует язык интерфейса.

Снимок исследования: **17 октября 2026 года**.

## Содержание

- 118 карточек компаний, групп и брендов; 27 отраслевых направлений.
- Каталог с поиском, фильтрами, избранным и экспортом CSV.
- Дневной приоритет: 6 графиков фабрик/производственных вакансий и 10 общих графиков компаний.
- Расширенный реестр ASP: 42 531 уникальный IDNO, отобранный по заявленным производственным видам деятельности.
- CNED: 12 913 исходных строк организаций с месячными кВт·ч за январь–апрель 2026 года.
- Конструктор запросов для дальнейшего поиска, методика и ссылки на источники.
- Документы: `Energy-Industry.xlsx`, `Energy-Analysis.pdf` и расширенная таблица `Energy-Day.xlsx`.

## Запуск

Готовый статический сайт находится в `dist/`; серверная часть и ключи API не требуются.

```sh
python3 -m http.server 8000 --directory dist
```

Откройте `http://localhost:8000`. Используйте HTTP-сервер: загрузка JSON через `fetch` не рассчитана на открытие HTML как локального файла.

## Структура и обновление

| Файл | Назначение |
| --- | --- |
| `dist/app.js` | Логика страниц, фильтров, экспорта и конструктора запросов |
| `dist/style.css` | Оформление |
| `dist/data.json` | Карточки, отрасли, источники и аналитические статусы |
| `dist/registry.json` | Отбор юридических лиц из ASP |
| `dist/public-energy.json` | Опубликованное потребление CNED |
| `dist/files/` | Документы для скачивания |
| `dist/language.js` | Выбор языка, мобильное меню, сохранение условий при переключении |
| `translations/*.ro.json` | Проверенные румынские переводы интерфейса и карточек |
| `prompt-template.js` | Исходный шаблон запросов; обе версии генерируются при сборке |
| `build-locales.py` | Сборка `app.ro.js`, `data.ro.json` и двуязычных шаблонов; ошибка при отсутствии перевода |
| `verify-locales.cjs` | Проверки двух языков, целостности фактов и генератора запросов |
| `build.py` | Генератор HTML входных страниц из данных |
| `make-workbook.py` | Генератор расширенной Excel-таблицы; требуется `openpyxl` |
| `verify.cjs` | Проверка данных, фильтров, шаблонов и ссылок; требуется Node.js |
| `RESEARCH-NOTES.md` | Происхождение данных и ограничения анализа |

После изменения списка карточек или направлений:

```sh
python3 build.py
python3 build-locales.py
node --check dist/app.js
node --check dist/app.ro.js
node verify.cjs
node verify-locales.cjs
python3 build-pages.py
node verify-locales.cjs pages-build
```

Для пересоздания расширенной таблицы:

```sh
python3 -m pip install openpyxl
python3 make-workbook.py
```

`dist/` намеренно хранится в Git: это готовая версия сайта, включая данные и документы. Для обычного статического хостинга укажите `dist` как корневую папку.

## GitHub Pages

Публичный адрес: **https://moldset-mmc.github.io/energy-md/**.

`python3 build-pages.py` создаёт папку `pages-build/` с путями для `/energy-md/`. Публикуемое содержимое этой папки находится в корне ветки `gh-pages`. В настройках GitHub Pages выбраны `Deploy from a branch`, ветка `gh-pages` и папка `/ (root)`. После изменения исходников нужно повторить сборку и обновить ветку публикации. Папка `pages-build/` исключена из ветки исходников.

## Как читать данные

Все карточки — кандидаты на проверку. **Фактические счета от 30 000 MDL/месяц и преобладание дневной нагрузки в карточках не подтверждены.** Оборот, установленная мощность и опубликованные часы работы не заменяют счёт и интервальные показания.

ASP показывает заявленные виды деятельности и адрес регистрации, который может отличаться от адреса производства. Отсутствие даты ликвидации не доказывает работающую фабрику. CNED содержит исходные строки, а не гарантированно уникальные организации: повторяющиеся названия не объединены. Фильтр 10 000 кВт·ч не равен денежному порогу.

Избранное хранится в браузере в `localStorage`. Приложение само не обогащает базу и не отправляет сообщения. Внешние поисковые ссылки открывают Google; шрифты загружаются из Google Fonts с системными запасными вариантами.
